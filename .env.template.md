# YouTube Video Transcriber & Summarizer using Gemini Pro

Environment configuration template for the YouTube video transcriber project.

## Setup Instructions

1. Copy this file:
   ```bash
   cp .env.template .env
   ```

2. Edit `.env` and add your API keys:
   ```
   GOOGLE_API_KEY=your_key_here
   ```

3. For Colab users:
   - No need to create `.env` file
   - Use: `userdata.set('GOOGLE_API_KEY', 'your-key')`
   - Or authenticate via: `!gcloud auth application-default login`

## API Keys

### Google API Key
- Get your key from [Google AI Studio](https://aistudio.google.com/apikey)
- Enable the Generative AI API

### YouTube API Key (Optional)
- Get from [Google Cloud Console](https://console.cloud.google.com/)
- Only needed if using YouTube search features

## Security

⚠️ **IMPORTANT**: Never commit `.env` file to version control!
- Add `.env` to `.gitignore`
- Always use `.env.template` for documentation
